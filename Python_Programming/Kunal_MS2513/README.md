# Python Programming (M.Sc. Part II)

This repository contains practical lab assignments, experiments, and code solutions for the **M.Sc. Computer Science (Part II) - Python Programming** curriculum.

---

## 📂 Repository Structure

```text
Python_Programming_Msc_II/
└── Assignment_I/
    └── Experiments.ipynb     # Lab experiments on core Python concepts
```

---

## 🧪 Experiments Covered

### **Assignment I**
- **Experiment 1:** Variable swapping using Python's tuple unpacking.
- **Experiment 2:** String indexing, slicing, and string reversal techniques.
- **Experiment 3:** List manipulation (appending and removing elements).

---

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Jupyter Notebook / JupyterLab or VS Code with Jupyter extension

### Running the Notebooks
1. Clone the repository:
   ```bash
   git clone https://github.com/Kunal-Kamod25/Python_Programming_Msc_II.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Python_Programming_Msc_II/Assignment_I
   ```
3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook Experiments.ipynb
   ```
