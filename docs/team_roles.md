# Team Roles

Roles are rough guidance, not rigid boundaries — with a 2-person team you'll
both touch most of the codebase. This exists so there's a default owner for
each area (reduces "I thought you were doing that" moments).

## [Name 1]
- Primary focus: [e.g. game engine, data pipeline]
- Secondary: [e.g. evaluation]

## [Name 2]
- Primary focus: [e.g. model architecture, training loop]
- Secondary: [e.g. report writing]

## Shared Responsibilities (both, always)
- Code review on each other's pull requests before merging to `main`
- Keeping PLAN.md and REPORT.md updated
- Weekly sync (recommend: 20-30 min, same day each week) to realign on
  Open Questions in PLAN.md
